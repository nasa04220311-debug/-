# -恐龍會計 (DinoAccounting) - 自動化數據管線與帳務異常快篩系統以 Python 數據工程與機器學習（Isolation Forest）打造的企業級輕量化帳務風控與報表自動化解決方案。📌 專案背景與核心痛點中小企業與後勤稽核部門在處理日常帳務時，常面臨以下痛點：人工對帳耗時易錯：海量 ERP、進銷存與銀行交易明細缺乏統一格式，耗費大量人工整理時間。隱性風險難以察覺：傳統依賴固定規則（Rule-based）的稽核方式，容易忽略偏離常態的異常拆單、手續費落差或高頻微額支出。《恐龍會計》 透過建立自動化 ETL 數據管線與 Isolation Forest（孤立森林） 無監督機器學習模型，將傳統數天的人工比對作業縮短至數秒完成，實現降本增效與零信任風險預警。🛠️ 系統架構與技術特點1. 數據清洗與整合管線 (Data Pipeline)運用 Pandas 建立自動化 ETL 管線，處理 6,000 筆 原始交易明細。實現自動欄位映射、資料型態轉換與遺漏值處理，產出標準化【資料合併】資料集。2. 機器學習異常快篩模型 (Isolation Forest)導入 sklearn.ensemble.IsolationForest 演算法進行無監督異常偵測。孤立樹狀分割：利用異常點「數量少、特徵顯著」的特性，透過隨機特徵分割樹快速孤立資料。異常分值計算：計算資料點在樹中的平均路徑長度，路徑越短代表越早被孤立，自動精準標記出 2,400 筆 偏離常態的【帳目異常】清單。高階防弊效益：無需預先標記或設定硬性條件，能自動抓出跨欄位、隱蔽性高的離群交易風險。3. 多軸度財務彙總與報表輸出科目總帳 (General Ledger)：自動彙總各大會計科目（差旅費、水電費、薪資支出、行銷廣告費、辦公用品費、餐費）之累計金額。商業對象分析：自動計算主要合作對象（如三花企業、橘貓工作室、汪汪商行等）之 AP（應付帳款）、AR（應收帳款）、毛利與毛利率（最高達 74.36%）。自動化匯出：透過 openpyxl / ExcelWriter 將多張工作表整合產出標準 Excel 報表。📊 專案成果範例產出之 Excel 活頁簿 (恐龍會計.xlsx) 包含四大核心工作表：工作表名稱筆數 / 範疇核心功能說明資料合併6,000 筆原始交易明細 ETL 清洗與標準化格式總帳6 大科目會計科目累計金額與大項費用總覽帳目異常2,400 筆經 Isolation Forest 演算法篩選之偏離常態異常追蹤清單對象彙總表5 大合作對象AP / AR / 毛利 / 毛利率多維度營運分析📁 檔案結構DinoAccounting/
